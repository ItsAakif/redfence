# ADR-0001: Reconnaissance and adoption of provisional definitions

- **Status:** accepted
- **Context:** Mandate section 2 requires beginning with repository
  reconnaissance and searching for existing A–D/G1–G9 definitions.
- **Finding:** The repository was empty at the start of implementation: no Git
  metadata, no documentation, and no pre-existing A–D/G1–G9 definitions.
- **Decision:** Adopt the mandate's provisional definitions verbatim, record the
  gap in `docs/benchmark-spec.md §0`, and do not invent alternatives. Preserve
  any future existing work.
- **Consequence:** If authoritative definitions are added later, they win.
